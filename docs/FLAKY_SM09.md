# Наблюдение нестабильности TC-SM-09 в Firefox

В `regression-release/run-2` проверка
`test_tc_sm_09_no_match_preserves_selection` один раз завершилась ошибкой:
после `choose('Green')` не появился `Remove Green`. В сохраненном DOM был открыт
список с единственной опцией Green, а поисковый input содержал Green.

Это ошибка предусловия проверки поиска: требуемый цвет не был выбран.
Снимок и DOM сохранены стандартным хуком Allure. Исходный результат находится
в `regression-release/run-2/firefox.xml`, `firefox.log` и `allure-results/`.
В повторном удаленном CI 41621308358 аналогичный симптом появился у TC-SM-06:
после выбора Green отсутствовал Remove Green. Результат этого CI — failure,
75/76 Passed; Allure с восстановленной историей и видеозаписи сохранены.
Тест не помечен skip/xfail, ожидание не ослаблено, автоматический retry не добавлен.

Одиночное наблюдение не позволяет отнести причину к продукту, фреймворку,
сети или нагрузке окружения. В остальных зафиксированных прогонах этот путь
проходил; различие статусов включено в расчет наблюдаемого Flaky Rate.

Для дальнейшего расследования следует повторить сценарий с Playwright tracing,
сохранением console/pageerror и сетевых событий, затем сопоставить последовательность
React input/change/mousedown/click с обновлением опции и нагрузкой компьютера.
Повторять только упавший тест ради исправления статистики нельзя: новое наблюдение
должно иметь отдельный ID запуска и не заменять исходный результат.
